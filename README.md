# Анализ временных рядов

Четыре лабораторные работы. Ноутбуки содержат код, результаты вычислений, графики и выводы. Данные сгенерированы в коде, для повторения расчётов скачивать наборы данных не нужно.

| Работа | Просмотр | Исходный код |
|---|---|---|
| 1. Генератор и первичный анализ | [Открыть отчёт](reports/lab-1.md) | [Jupyter Notebook](lab_time_series_generator.ipynb) |
| 2. Декомпозиция и сезонность | [Открыть отчёт](reports/lab-2.md) | [Jupyter Notebook](lab_02_decomposition.ipynb) |
| 3. Проверка стационарности | [Открыть отчёт](reports/lab-3.md) | [Jupyter Notebook](lab_03_stationarity.ipynb) |
| 4. Оценка базовых прогнозов | [Открыть отчёт](reports/lab-4.md) | [Jupyter Notebook](lab_04_forecasting.ipynb) |

Три отчётных изображения первой работы находятся в [images](images). При повторном запуске генератор сохраняет новый CSV в папку `generated` и перезаписывает три отчётных PNG. Шаг временного ряда — 5 минут, начало — полночь даты запуска.

## Запуск

Используйте Python 3.12. В корне проекта установите зависимости и откройте JupyterLab.

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```

Откройте нужный ноутбук и выполните все ячейки по порядку. Для генерации и моделирования заданы начальные значения генераторов случайных чисел.
